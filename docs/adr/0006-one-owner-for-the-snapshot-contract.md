# Give the Snapshot contract one owner

Six places composed the schema-version-1 Snapshot by hand — the current, failure, setup, and configuration-error builders spread over four collector modules, the developer demonstration, and the JavaScript test fixtures — and their shapes had drifted: the setup Snapshot's bar lacked `kind`, the configuration-error Snapshot had no sections and no bar, and the JavaScript reader compensated silently by recomputing the bar for most states. `scripts/clawbar_snapshot.py` now owns the contract through one builder bound to the previous Snapshot, the refresh interval, and a clock, with exactly four entrances (current, failure, setup, configuration error). The schema version, the resolution sources, the closed set of failure kinds, the section shapes, the bar derivation, and the Last Known Metadata carry-forward live inside it, nothing mutates a Snapshot after it is built, and the demonstration and the committed JavaScript fixtures are generated through the same entrances so the contract has one set of examples that a drift test keeps current.

## Consequences

- The bar is derived from the recorded Gateway state alone: healthy counts current Automation Failures (critical when any, otherwise healthy); degraded adds one to that count (warning when no Automation Failure); unstable is one warning; offline and configuration error are one critical; no data and Gateway Setup Required are zero warning with `kind: "none"`. `kind` means only whether the count is positive. Stale stays age-derived on the reader side.
- A Degraded Gateway carries the previous Last Known Metadata forward whenever any section is unavailable, provided that retained metadata has every section available; the former Fleet-only special case is generalised, and CONTEXT.md's Last Known Metadata definition was tightened to match.
- Private state files (`gateway-candidates.json`, `gateway-verified-target.json`) stop borrowing the Snapshot's schema version and carry their own, as the Incident state already did; the shared loader no longer takes a version argument.
