# Show Agent registration, not Agent Activity

Clawbar displays Agents reported by `agents.list` as Registered Agents with a static green presence dot, but does not claim Working, Waiting, or Idle state. Accurate short-lived Agent Activity requires a persistent Gateway event connection; the available `operator.read` stream carries broader session and Task fields than Clawbar's Operational Metadata allowlist, and a direct client must handle Gateway credentials. A companion OpenClaw plugin could reduce that stream before local IPC, but its installation, lifecycle, and trusted privacy boundary are disproportionate to this read-only signal board. Clawbar therefore keeps its bounded CLI collector, preserves previous Task Result as a separate historical fact, and removes Working Agent counts from the bar.
