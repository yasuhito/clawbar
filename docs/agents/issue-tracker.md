# Issue Tracker

Clawbar uses Beads Rust (`br`) with repository-local state under `.beads/`.

- Create: `br create`
- Ready work: `br ready`
- Show: `br show <id>`
- Dependencies: `br dep ...`
- Update: `br update <id> ...`
- Close: `br close <id>`
- Sync: `br sync`

Tickets produced by engineering skills must be created in Beads and must encode blocking edges with Beads dependencies. Work blockers-first; do not mirror tickets into GitHub Issues unless explicitly requested.
